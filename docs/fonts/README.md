# 普惠体字体替换

原 AXIS Regular 的全部使用位置改为阿里巴巴普惠体 3.0 65 Medium；原 AXIS Medium 改为 75 SemiBold。中文、拉丁、数字及标点均使用所选普惠体，不做字形混合、基线平移、缩放、补字或文本转换。所有客户端语言使用相同规则。其他字体的使用位置不变。

替换 11 个 Lua 文件的 20 处引用，删除原 AXIS Regular、Medium 及无引用的 Extrabold 文件。此前的 AXIS 复用方案在独立旧分支，从未合并，本分支从 develop 开始，不带入其代码、生成字体和审计工具。

## 来源

字体文件直接复制自已验证的公开镜像，内嵌版本 3.01，未经修改或格式转换；固定提交及 SHA-256 见 sources.json。官方下载此前返回 403，未与官方包哈希比对。官方入口 https://www.alibabafonts.com/ 。法律声明转载文件随字体保留，其来源链接在文件内。

## 验证与安装

将完整插件目录安装为 Interface/AddOns/FFXIV_UI，添加字体后完全重启游戏。检查菜单、目标及焦点、施法条、经验条、坐标、光环倒计时的中文和数字；检查常用 UI 缩放、描边、长名字、战斗及 /reload，确认无裁切、重叠或 Lua 报错。字体间字宽与行度量不同，离线加载不能代替游戏验收。

本机使用 fontTools 检查文件哈希、字重及 GB2312 汉字覆盖，Pillow 检查加载，Lua 5.1 检查全部 Lua 语法，并检查旧路径无残留及新路径存在。实测结果见 validation.json；真实 WoW 验收尚未执行。

## 开发流程

任务分支和独立工作树从最新 develop 建立；本机验证后经 PR 合并 develop，真实客户端验收后再经 PR 合并 main。当前不将未经游戏验收的字体更换作为正式发布。
