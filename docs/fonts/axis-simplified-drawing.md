# 常用多繁字的简体补绘

本次在复用字体上新增 61 个独立简体字形。先按《通用规范汉字表》（2013）一级 3500 字取交集，再筛选上一轮 `ambiguous` 中尚未获准复用的多繁缺字。判断“没有合适日式异体”的操作口径为：现有来源及逐字审核中没有已批准的无上下文映射；这不是穷尽所有历史字形的证明。已有可用映射保持不变，不为同一个简体码点选取某个繁体词义。

范围由构建脚本重新计算并与绘制配方严格对齐，新增、遗漏或字典改变会停止构建。已批准复用的“勋、娴、艳”等不在这 61 字中，其他单一对应或尚未找到候选的常用缺字也不纳入本轮。

## 设计与产物

- 原字体 1000 units/em；新字全角 advance 为 1000，按原字高、边距、平切端部和黑体字重布置。
- 可用结构直接取原 AXIS 的完整闭合部件轮廓，含内孔。偏旁如亻、氵、扌、犭、艹、罒、辶和阝均有明确供体及轮廓索引。
- 缺失的简体结构使用项目手绘笔画，例如丰、发、夹、门、贝、钅、纟、饣。未导入其他字体轮廓；对照图灰色国标黑体仅供检查字形结构，不参与生成。
- 部件缩放后补偿过细笔画，并按非零绕数处理内孔与嵌套结构，再合并交叠轮廓。源曲线仅在新字的部件加工中细分；原字形的 Type2 程序保留。
- CFF、字符映射、字形计数和横竖度量表扩展到 9415 个字形。新增 CID 属于自定义 `AXISCJK/Custom` 字集，不冒称 Adobe 标准 CID。

绘制配方：[axis_drawings.py](../../tools/axis_drawings.py)。几何处理：[axis_outline_geometry.py](../../tools/axis_outline_geometry.py)。构建入口：[build_axis_drawn.py](../../tools/build_axis_drawn.py)。逐字坐标范围和输入哈希见 [补绘覆盖报告](axis-drawn-coverage.json)。这些字是项目绘制的 AXIS 风格初版，不是原厂字形，不宣称与原厂设计完全相同。

## 构建与预览

```sh
.venv-fonts/bin/python -m pip install -r tools/requirements-fonts.txt
.venv-fonts/bin/python tools/build_axis_font.py
.venv-fonts/bin/python tools/build_axis_drawn.py
.venv-fonts/bin/python tools/preview_axis_drawn.py
.venv-fonts/bin/python -m unittest discover -s tests -v
```

新文件为 `Media/Fonts/AxisRegular-CJKDrawn.ttf`，独立名称 `AXIS CJK Drawn`；原始字体和旧复用版均保留。两种衍生字体仍为忽略的本地产物，不随仓库分发。源字体原有许可限制仍适用。

预览生成两张总览及一张 16/24/32/48px 混排图。可通过 `--reference /path/to/reference.ttf` 加入灰色结构对照字；该选项只影响预览，不影响字体。预览 PNG 为忽略的本地产物。

中文客户端按“补绘版 → 纯复用版 → 客户端字体 → 原指定字体”尝试加载。添加新字体后需完全重启游戏。这个顺序仍只是文件加载回退，不能填补补绘版剩余的 263 个常用缺字。
