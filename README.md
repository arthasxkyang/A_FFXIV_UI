## 界面字体

原 AXIS Regular 全部改用普惠体 3.0 **65 Medium**，原 AXIS Medium 改用 **75 SemiBold**，包含汉字、英文和数字。安装到 `Interface/AddOns/FFXIV_UI` 后完全重启游戏。来源、验证和开发流程见 [字体说明](docs/fonts/README.md)。
